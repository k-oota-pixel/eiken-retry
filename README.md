# eiken-retry

選択肢の日本語の意味はページ内に収録し、外部翻訳サービスへの通信なしで表示します。
問題データ・採点・学習記録・Firebase同期の仕様は維持しています。

## Dictionary data

The embedded glossary uses selected entries from [EJDict](https://github.com/kujirahand/EJDict), public-domain dictionary data, with additional Japanese meanings for expressions and grammar choices.
